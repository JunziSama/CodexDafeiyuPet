# 大肥鱼 Codex 增强桌宠

这是由 Codex 真实工作状态驱动的 Windows 大肥鱼增强桌宠。程序包含 106 个透明 WebM 动画、拖拽、抛掷、桌面碰撞、窗口吸附、气泡、右键菜单和托盘控制器。它是独立程序，不由 Codex 内置“显示宠物”入口控制。

## 开关流程

- Windows 登录后，托盘控制器驻留但不会显示桌宠，直到检测到 Codex Windows 客户端。
- Codex 启动且“随 Codex 自动启动”开启时，增强桌宠自动出现。
- 所有 Codex 窗口退出后，增强桌宠按右键“Codex 退出方式”执行退场；可选择当前动画加告别、仅告别、仅当前动画或随结束气泡同步消失，默认仅告别动画。
- 托盘“彻底退出”会同时关闭桌宠并禁用后续自动启动。
- 从开始菜单运行“大肥鱼 Codex 增强桌宠”会重新启用自动伴随。
- Codex 左下角“显示宠物”只控制 Codex 原生宠物，不控制本增强桌宠。
- 气泡默认显示 `Codex`；收到任务 Hook 后显示当前模型，例如 `GPT-5.6 Sol`。
- 桌宠右键菜单提供五档动画频率、五档移动频率以及独立的“仅水平移动”。
- 点击回应和右键手选动画不会被 Hook 或闲置调度半途切换；任务气泡立即更新，任务动画在当前片段结束后接续。
- 6 个工作状态动画由 Codex 任务提示驱动；6 个余额动画只允许手选，不推测 Codex 余额；随机池为 83 个动画。
- Windows 角色有效区域使用张开/抓紧手套光标；加载失败自动回退 Qt 标准手形。
- 播放器按需创建并采用 8 MiB 首帧 LRU、预测预热、单线程常驻 FFmpeg 与 10 分钟片段边界回收；窗口隐藏后停止解码和预热。
- 高于 90 Hz 的显示器上，移动、拖拽、抛掷和 Q 弹计时跟随刷新率，物理按真实时间和子步积分运行。
- “隐藏桌宠”会持久化，任务事件不会自动把它重新显示；使用托盘“显示大肥鱼”恢复。

## 状态反馈与隐私

Codex Hooks 只把事件类型、工具名称、成功/失败等必要状态送到 `127.0.0.1` 的令牌认证桥接端口；不转发用户提示词、命令正文、工具输入、工具输出或对话记录。首次启用 Hooks 时需要在 Codex 中审核并信任其精确定义。

托盘“设置与状态”会显示 Hook 最近事件、当前模型、桥接结果，以及最近事件是否实际用于桌宠。只有检测到 Codex Windows 桌面客户端时 Hook 才会驱动宠物；浏览器侧边问答等其他界面产生的 Hook 会标为“已收到但忽略”，不会启动或唤回宠物。如果显示“从未收到”，请在相同用户环境的 Codex CLI 输入 `/hooks`，审核并信任当前定义。

## 桌宠右键菜单

菜单只保留桌宠相关功能，包括动画、显示大小、置顶、隐藏/退出、“仅水平移动”和“窗口吸附”。窗口吸附默认关闭，阈值为 20 逻辑像素，可吸附屏幕边缘和普通窗口边缘；拖拽和飞行过程中不吸附，在释放或物理停稳后判断。

## 安装与卸载

以 PowerShell 运行：

```powershell
pwsh -File .\scripts\install-codex.ps1
pwsh -File .\scripts\uninstall-codex.ps1
```

安装器会保留现有的其他 Codex Hooks，只增删带有本程序路径标识的 Hook 条目。
卸载前请先从系统托盘选择“彻底退出”，避免删除正在运行的 Qt 文件。
